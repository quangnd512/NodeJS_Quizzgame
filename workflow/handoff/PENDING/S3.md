## TASK 1 — Fix bug Resume Exam (CRITICAL, 1 file)

**File:** `mobile/src/screens/exam/ExamListScreen.tsx`

**Vấn đề:** `alertShown` dùng `useState` → stale closure → dialog "phiên thi dở" 
KHÔNG hiện lại khi người dùng quay về ExamListScreen sau khi thi xong.

**Nguyên nhân kỹ thuật:** Khi focus lại, `setAlertShown(false)` được gọi nhưng 
closure của async callback vẫn thấy giá trị cũ (`true`) → điều kiện `!alertShown` 
luôn `false` → alert không chạy.

**Cách sửa chính xác (3 bước):**

Bước A — Đổi import: thêm `useRef` vào import nếu chưa có
```typescript
import React, { useCallback, useEffect, useRef, useState } from 'react';
```

Bước B — Đổi khai báo state (dòng ~50):
```typescript
// XÓA dòng này:
const [alertShown, setAlertShown] = useState(false);

// THÊM dòng này:
const alertShownRef = useRef(false);
```

Bước C — Cập nhật useFocusEffect (dòng ~52-100):
```typescript
useFocusEffect(
  useCallback(() => {
    if (!sessionToken) return;
    alertShownRef.current = false;          // ← đổi từ setAlertShown(false)

    getActiveExamSession(sessionToken)
      .then((res) => {
        if (res.session && res.session.remainingSeconds < 0) {
          setActiveSession(null);
          return;
        }
        setActiveSession(res.session);
        if (res.session && res.session.remainingSeconds >= 0 && !alertShownRef.current) {  // ← đổi
          Alert.alert(
            'Đang có phiên thi dở',
            `Bạn đang có phiên thi "${res.session.title}" chưa hoàn thành. Muốn tiếp tục hay hủy phiên cũ?`,
            [
              {
                text: 'Tiếp tục phiên cũ',
                style: 'cancel',
                onPress: () => {
                  navigation.navigate('ExamTaking', { session: res.session });
                },
              },
              {
                text: 'Hủy phiên cũ',
                style: 'destructive',
                onPress: async () => {
                  try {
                    await abandonExam(sessionToken, res.session.id);
                    setActiveSession(null);
                  } catch (err) {
                    const msg = err instanceof Error ? err.message : 'Không thể hủy phiên.';
                    Alert.alert('Lỗi', msg);
                  }
                },
              },
            ],
          );
          alertShownRef.current = true;     // ← đổi từ setAlertShown(true)
        }
      })
      .catch(() => { setActiveSession(null); });
  }, [sessionToken, navigation]),            // ← XÓA alertShown khỏi deps array
);
```

**KHÔNG cần AsyncStorage** — backend API `getActiveExamSession` đã đủ.
