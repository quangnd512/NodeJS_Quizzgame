# PENDING — Hộp thư đến (chỉ lệnh ĐANG CHỜ)

Thư mục này **chỉ** chứa `SX.md` của những session chưa xử lý xong.

- Làm xong → `mv PENDING/SX.md archive/SX.done.md`
- Kế hoạch dài hạn → để ở `../backlog/`, **không** để ở đây
- File `.done.md` → để ở `../archive/`, **không** để ở đây

Xem đầy đủ vòng đời tại `../README.md`.
