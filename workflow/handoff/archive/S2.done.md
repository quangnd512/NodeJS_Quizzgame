🔧 CHI TIẾT KỸ THUẬT:
- Thư mục MỚI: mobile/ (React Native + Expo + TypeScript). KHÔNG đụng vào frontend/
  hiện có (frontend/ vẫn tiếp tục chạy bình thường, không sửa gì ở đó).
- KHÔNG cần sửa backend/ code — verifyFirebaseToken (backend/src/middleware/auth.middleware.ts)
  đã provider-agnostic (chỉ verify Firebase ID token, không phân biệt Google/Apple).
  Chỉ cần bật thêm provider "Apple" trong Firebase Console (cấu hình, không phải code) —
  nếu cần quyền truy cập Firebase Console, hỏi người dùng.
- API tái sử dụng (đã có sẵn, xem chi tiết docs/api/drafts/mobile-foundation.yaml):
    POST /api/auth/login      — đổi Firebase ID token → JWT nội bộ (hạn 7 ngày)
    GET  /api/users/me        — lấy hồ sơ, kiểm tra đã chọn môn (subjects) chưa
    POST /api/users/subjects  — lưu môn học lúc onboarding
- Admin: dùng lại cơ chế header "X-Admin-Secret" hiện có (backend/src/middleware/admin.middleware.ts),
  KHÔNG qua Firebase/JWT. Trên mobile lưu secret bằng expo-secure-store (thay vì
  sessionStorage như web, vì mobile cần tồn tại sau khi tắt app).
- Lưu trữ nhạy cảm (JWT, admin secret) BẮT BUỘC qua expo-secure-store (Keychain/Keystore
  mã hoá) — TUYỆT ĐỐI KHÔNG dùng AsyncStorage thường (plain text).
- Thư viện dự kiến: Expo, React Navigation, tích hợp Firebase Auth (Google + Apple) qua
  SDK phù hợp Expo (vd @react-native-google-signin/google-signin hoặc Firebase JS SDK
  tuỳ S2 đánh giá — miễn đăng nhập ra được Firebase ID Token hợp lệ để gọi POST /api/auth/login),
  expo-apple-authentication, expo-secure-store.

⚠️ EDGE CASE CẦN LƯU Ý:
- Apple CHỈ trả họ tên đầy đủ ở LẦN ĐĂNG NHẬP ĐẦU TIÊN qua Firebase — phải lưu ngay lúc đó,
  các lần đăng nhập sau sẽ không có nữa.
- Apple có thể trả email ẩn danh (relay email) — vẫn hợp lệ vì cột `email` trong User
  cho phép bất kỳ chuỗi duy nhất (unique, nullable).
- Nút "Đăng nhập bằng Apple" CHỈ hiện trên iOS, ẩn hoàn toàn trên Android.
- Google Sign-In trên Android cần khai báo SHA-1 fingerprint trong Firebase Console
  (cả bản debug lẫn bản phát hành sau này) — báo người dùng nếu cần họ cung cấp/tạo.
- "Đăng nhập bằng Apple" cần tài khoản Apple Developer Program (99 USD/năm) đã cấu hình
  Sign in with Apple để TEST THẬT trên thiết bị/giả lập iOS thật. Nếu người dùng CHƯA có
  tài khoản này, làm nút bấm nhưng có thể tạm KHÔNG test được đầu-cuối trên iOS thật —
  báo lại người dùng rõ tình trạng này, đừng tự ý bỏ task.
- User CŨ đã có sẵn môn học (đăng nhập từ web trước đó) → mở app mobile lần đầu KHÔNG
  bắt onboarding lại (kiểm tra qua GET /api/users/me → subjects.length > 0), vào thẳng
  khung điều hướng chính.
